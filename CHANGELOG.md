# Journal des versions

Format : version marketing (numéro de build). Les numéros sont alloués par `tools/delivery_version.py` et le registre GitHub, jamais à la main — voir [la procédure de versionnement](docs/IPA_VERSIONING.md).

## 1.111 (113) — première version publique

- Première version publiée d'Eudes : chat en streaming avec un serveur compatible OpenAI, modèle Apple sur l'appareil, modèles GGUF exécutés localement, images avec les modèles texte et vision, assistant vocal, recherche Web.
- Distribution hors App Store par sideloading ; licence **GNU GPL v3** avec une permission supplémentaire au sens de la section 7 pour les magasins d'applications.
- Compilation et tests sur des runners macOS hébergés par GitHub, sans runner auto-hébergé.
- Le développement antérieur à cette publication s'est fait dans un dépôt privé ; son journal n'est pas publié.
